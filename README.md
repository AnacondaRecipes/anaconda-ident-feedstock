Installing anaconda-ident
==================

Installing `anaconda-ident` from the main channel can be achieved by:

```
conda install anaconda-ident
```

It is possible to list all of the versions of `anaconda-ident` available on your platform with `conda`:

```
conda search anaconda-ident
```
